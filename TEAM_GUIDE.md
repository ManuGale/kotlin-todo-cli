```bash

```

---

# ANTES DE TRABAJAR

Actualizar cambios:

```bash
git pull origin main
```

---

# 📌 HACER COMMITS

```bash
git add .
git commit -m "Descripción del cambio"
```

---

# SUBIR CAMBIOS

```bash
git push origin nombre-rama
```

Ejemplo:

```bash
git push origin feature-crud-tareas
```

---

# PROHIBIDO

- NO trabajar en main
- NO hacer commits gigantes
- NO borrar archivos ajenos
- NO subir archivos innecesarios

---

# OBJETIVO

Cada integrante debe realizar mínimo 5 commits reales relacionados a su módulo.

# Team Guide

## Flujo de trabajo

1. Crear rama
2. Trabajar únicamente en su módulo
3. Realizar commits descriptivos
4. Hacer push a su rama
5. Crear Pull Request
6. Esperar revisión antes de merge

---

# Convención de commits

## feat

Nueva funcionalidad (`feat: agregar registro de tareas`)

## fix

Corrección de errores (`fix: corregir lectura de archivo`)

## docs

Documentación (`docs: actualizar README`)

## test

Pruebas (`test: agregar pruebas manuales`)

---

# Recomendaciones

- No modificar archivos de otros compañeros
- Mantener código limpio
- Probar antes de hacer push
- Mantener nombres descriptivos
