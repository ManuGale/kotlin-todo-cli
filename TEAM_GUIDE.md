# Team Guide

## Flujo de trabajo
1. Crear rama
2. Trabajar únicamente en su módulo
3. Realizar commits descriptivos
4. Hacer push a su rama
5. Crear Pull Request
6. Esperar revisión antes de merge

---

# Convención de commits

## feat
Nueva funcionalidad (`feat: agregar registro de tareas`)

## fix
Corrección de errores (`fix: corregir lectura de archivo`)

## docs
Documentación (`docs: actualizar README`)

## test
Pruebas (`test: agregar pruebas manuales`)

---

# Recomendaciones
- No modificar archivos de otros compañeros
- Mantener código limpio
- Probar antes de hacer push
- Mantener nombres descriptivos
